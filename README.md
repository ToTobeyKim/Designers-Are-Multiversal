# Designers are Multiversal

Generative data visualization of the SCAD Graphic Design and Visual Experience curriculum.

Open `index.html`. The page is one self-contained file with its own CSS, JavaScript and SVG. It loads only Roboto from Google Fonts.

## Files

- `index.html` is the website, with the motion poster first and the ten static posters in the left menu
- `media/designers-are-multiversal-motion.mp4` is the motion poster, 1440 × 2040, 30 fps, H.264, 15 second loop
- `media/posters/` holds the ten static compositions as PNG, 1440 × 2040
- `media/designers-are-multiversal-A1.pdf` is the A1 poster, 594 × 841 mm, vector
- `media/designers-are-multiversal-A1.svg` is the same A1 poster as SVG
- `media/system-demo.mp4` is a screen capture of the system generating variations

## Publish on GitHub Pages

1. Create a new repository and upload everything in this folder, keeping the `media` folder as it is.
2. In the repository, open Settings, then Pages, and set the source to the `main` branch and the root folder.
3. The site appears at `https://<user>.github.io/<repository>/` after a minute.

Every file is under 100 MB.
