      About

      Concept

      Graphic design is not a ladder. A course that looks niche on paper, like Visual Analysis of Static Content, turns up inside a poster, a dashboard, an exhibit and a brand. At SCAD every course is a building block, and the same blocks recombine into very different kinds of work. Adaptability is not an option for a designer, it is the requirement.

      The poster sets the curriculum as a fixed field of stars. Each category of design work is a constellation drawn across it. Change the category and the same stars make a different picture. Draw again and the same category finds another route.

      Data

      Every word on the rings comes from the SCAD catalog pages for the B.A., B.F.A., M.A. and M.F.A. in Graphic Design and Visual Experience. That is 35 GRDS and GDVX course descriptions, set in full. The left text column on the poster is SCAD’s own description of the program. The right column states the design strategy.

      GDVX 779 Graduate Internship has no description in the catalog, so its slice carries its title only. GRDS 201 and the five core principles carry no description by design. They are the center the rest is built on.

      Rules

      • GRDS 201 sits at the center. GRDS 205, 285, 301, 323 and 348 surround it as five numbers with no first step.
      • Every other course belongs to one core principle and sits in that principle’s fifth of the circle.
      • Each ring holds one course per principle, in course number order. The groups are uneven on purpose, eight, seven, seven, five and eight courses, so the outer rings thin out and empty slices are real gaps in the data.
      • Type size comes from the longest entry, GRDS 440 Studio III at 754 characters plus its title. On each ring the type is set at the largest size where that entry still fits its slice, so the type grows ring by ring and every description fits. The text is held at 45% white so it reads as a wireframe beneath the lines.
      • A course joins a category when its title or description contains one of that category’s keywords. The catalog’s standard safety sentence is left out of the matching.
      • Each line is a straight, closed route through three or more courses of one category. Routes never pass through 201 or the five principles.
      • No two routes are alike. Each takes its own set of courses, its own order, its own weight from a hairline to a heavy stroke, and its own opacity. In the all nine view a category with more courses draws more lines.
      • The motion poster stacks the nine categories one by one. Each arrives through quick cuts between alternate versions, then settles on top of the others until all nine stand together. Then the field clears and a new set of routes begins. The loop is 15 seconds and never repeats the same routes.

      Tools and AI workflow

      The concept, structure, sketch and poster layout were set by the designer in Illustrator. Claude (Anthropic) was used as a critical partner on the strategy, then to extract the catalog text from the PDF, measure every description in Roboto, fit the type to the rings and write the HTML, SVG and JavaScript. The ring text is set once, ahead of time, and the lines are drawn on a canvas so the page stays fast. Every rule above was decided in that conversation before any code was written.

      Key decisions

      • Prerequisites were set aside. The piece treats every course as a building block, not a step.
      • Full descriptions instead of excerpts, so every word stays readable on the A1.
      • Undergraduate GRDS and graduate GDVX share one field.
      • Studio and practice first held eleven courses and pulled the circle out of shape. GRDS 400 moved to audience, GDVX 789 to type, form and language, and GDVX 792 to physical production.
      • Lines are straight. Curvature carries no meaning in the data, so the routes show only which courses connect.
      • The colored lines are the message and the descriptions are the structure, so the lines carry all the colour and weight.
